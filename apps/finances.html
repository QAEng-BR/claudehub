☁️ Sincronización en tiempo real
¿Cómo funciona?
Ambos teléfonos se conectan a la misma base de datos Firebase. Cualquier cambio que haga uno, el otro lo ve al instante.

Pasos para activarlo:
1. Ve a console.firebase.google.com
2. Crea un proyecto → Realtime Database → Modo prueba
3. Copia la URL de la base de datos y pégala abajo
4. Pon el mismo Código familiar en ambos teléfonos
